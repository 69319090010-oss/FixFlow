# FixFlow - Mobile Web App Starter

## วิธีเปิดใช้งาน
1. แตกไฟล์ ZIP
2. เปิดโฟลเดอร์ `fixflow_starter`
3. ดับเบิลคลิก `index.html` หรือเปิดด้วย Live Server ใน VS Code

## บัญชีทดลอง
- ผู้แจ้ง: `student` / `demo123`
- ช่าง: `technician` / `demo123`
- ผู้อนุมัติ: `director` / `demo123`

## ฟังก์ชันในต้นแบบ
- เข้าสู่ระบบแบบจำลองและแยกบทบาท
- หน้าหลักและสรุปจำนวนคำร้อง
- ส่งคำร้องแจ้งอุปกรณ์ชำรุด
- ติดตามสถานะและประวัติ
- เจ้าหน้าที่ประเมินราคาและอัปเดตงาน
- ผู้อนุมัติอนุมัติ/ไม่อนุมัติพร้อมเหตุผล
- เก็บข้อมูลตัวอย่างใน localStorage ของเบราว์เซอร์

## ข้อจำกัดและความปลอดภัย
นี่เป็น Front-end prototype สำหรับทดลอง UI/Flow เท่านั้น:
- ยังไม่มีฐานข้อมูลออนไลน์หรือระบบยืนยันตัวตนจริง
- ข้อมูลอยู่ในเบราว์เซอร์เครื่องที่เปิดใช้งานเท่านั้น
- รูปภาพที่เลือกยังไม่ได้อัปโหลดหรือบันทึก
- ห้ามใช้เลขบัตรประชาชนเป็นรหัสผ่าน
- ก่อนใช้งานจริงต้องเพิ่ม backend, authentication, role-based access control,
  การจัดเก็บรูปภาพอย่างปลอดภัย, audit log และการสำรองข้อมูล
